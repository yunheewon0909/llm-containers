# Local AI Containers

Docker-based local AI stack using LM Studio as the inference backend.

## Services

| Service | Local address |
| --- | --- |
| Open WebUI | `http://localhost:3000` |
| Hermes gateway | `http://localhost:8642` |
| Hermes Agent Dashboard | `http://localhost:9119` |
| Hermes virtual desktop | `vnc://localhost:5901` |
| SearXNG | `http://localhost:8888` |
| Crawl4AI | `http://localhost:11235` |

Open WebUI, Hermes, and SearXNG store persistent runtime data in Docker named
volumes. Crawl4AI uses temporary filesystems for caches, jobs, and artifacts;
save any required extraction results in the calling client.

## Architecture

```text

       │
       │ host.docker.internal:1234
       │
Docker ├── Open WebUI
       ├── Hermes
```

## Initial Setup

Create the shared Docker network once:

```bash
docker network create local-ai-network
```

Start SearXNG:

```bash
cd searxng
docker compose up -d
```

Start Crawl4AI:

```bash
cd ../crawl4ai
test -f .env || (umask 077; printf 'CRAWL4AI_API_TOKEN=%s\n' "$(openssl rand -hex 32)" > .env)
chmod 600 .env
docker compose config --quiet
docker compose up -d --wait --wait-timeout 120
```

Crawl4AI needs a non-empty API token. See the [Crawl4AI guide](crawl4ai/README.md)
for request examples, authentication, temporary data, and troubleshooting.

Start Open WebUI:

```bash
cd ../open-webui
docker compose up -d
```

Initial Hermes setup:

```bash
cd ../hermes
docker compose run --rm hermes setup
docker compose up -d --build
```

To remove the Hermes container and all persistent Hermes data, see
[Reset Hermes](hermes/README.md#reset-hermes).

## LM Studio Token Usage Monitoring

You can monitor the actual token usage of local LLM inference running through LM Studio in real time.

The following command reads LM Studio model output logs and displays both per-request and cumulative token usage.

```bash
lms log stream --source model --filter output --json --stats |
awk '
{
    line=$0

    if (match(line, /"promptTokensCount":[0-9]+/)) {
        s=substr(line,RSTART,RLENGTH)
        sub(/.*:/,"",s)
        input=s+0
    } else next

    if (match(line, /"predictedTokensCount":[0-9]+/)) {
        s=substr(line,RSTART,RLENGTH)
        sub(/.*:/,"",s)
        output=s+0
    } else output=0

    if (match(line, /"totalTokensCount":[0-9]+/)) {
        s=substr(line,RSTART,RLENGTH)
        sub(/.*:/,"",s)
        total=s+0
    } else total=input+output

    requests++
    total_input+=input
    total_output+=output
    total_all+=total

    printf "\nRequest #%d\n", requests
    printf "  Input : %'\''d\n", input
    printf "  Output: %'\''d\n", output
    printf "  Total : %'\''d\n", total

    printf "\nCumulative\n"
    printf "  Input : %'\''d\n", total_input
    printf "  Output: %'\''d\n", total_output
    printf "  TOTAL : %'\''d\n", total_all
    fflush()
}'
```

Example output:

```text
Request #1
  Input : 96,117
  Output: 996
  Total : 97,113

Cumulative
  Input : 96,117
  Output: 996
  TOTAL : 97,113
```

- **Input**: Total number of tokens processed as input for the request.
- **Output**: Total number of tokens generated by the model. For reasoning models, this includes reasoning/thinking tokens.
- **Total**: Input + Output.
- **Cumulative**: Total usage accumulated since the monitor was started.

Because the monitoring is performed directly from LM Studio's model logs, it captures inference regardless of which client generated the request, such as Hermes Agent, OpenCode, or Open WebUI.

> Cumulative values are kept only for the lifetime of the command and reset when the monitor is restarted.

## Crawl4AI and Search → Fetch

Crawl4AI runs the official `unclecode/crawl4ai:0.9.4` ARM64-compatible image.
Plain Markdown extraction does not require an LLM API key.

| Client | Search | Fetch |
| --- | --- | --- |
| macOS host | `http://localhost:8888` | `http://localhost:11235` |
| Shared-network container | `http://searxng:8080` | `http://crawl4ai:11235` |

The caller searches SearXNG, selects up to three distinct HTTP(S) URLs, sends
those URLs to Crawl4AI's `/crawl` endpoint with a Bearer token, and passes
successful Markdown and source URLs to the model. `GET /health` is public;
other API endpoints require the token stored in `crawl4ai/.env`.

As of 2026-10-09, token authentication, real page extraction, shared-network
connectivity, and SearXNG → Crawl4AI extraction were verified. A request using
SearXNG's GitHub engine returned 30 results; fetching the official Crawl4AI
repository produced 47,119 Markdown characters. The default search engines
were rate-limited or CAPTCHA-blocked during verification, so that successful
test used `engines=github` per request without changing the default settings.

Adding the service does not replace Open WebUI or Hermes's existing fetch
tool. Client-specific tool integration remains a separate step. General web
searches still need a responsive general-purpose SearXNG engine. Crawl4AI
has a 4 GiB memory limit and 1 GiB private shared memory.

See [Crawl4AI usage and verification](crawl4ai/README.md).

## Remote Access with Tailscale

Services remain bound to `127.0.0.1`.

On this host, OpenClaw manages the default HTTPS port `443`. Open WebUI uses
HTTPS port `10000`, while its local Docker port remains `3000`.

Open WebUI:

```bash
/Applications/Tailscale.app/Contents/MacOS/Tailscale serve --bg --https=10000 localhost:3000
```

Open from another tailnet device at `https://<mac-magicdns-name>:10000/`.

SearXNG web UI:

```bash
/Applications/Tailscale.app/Contents/MacOS/Tailscale serve --bg --https=8443 localhost:8888
```

Hermes Agent Dashboard:

```bash
/Applications/Tailscale.app/Contents/MacOS/Tailscale serve --bg --https=9119 localhost:9119
```

Hermes VNC uses raw TCP Serve rather than HTTP/HTTPS Serve:

```bash
/Applications/Tailscale.app/Contents/MacOS/Tailscale serve --bg --tcp=5901 tcp://localhost:5901
```

Check:

```bash
/Applications/Tailscale.app/Contents/MacOS/Tailscale serve status
```

Use the displayed MagicDNS name from another tailnet device. Open the web
services with their displayed `https://` URLs and VNC with:

```text
vnc://<mac-magicdns-name>:5901
```

Hermes generates its VNC and Dashboard credentials in the persistent
`hermes-data` volume. See [Hermes VNC and Dashboard credentials](hermes/README.md#vnc-and-dashboard-credentials)
for the retrieval commands.

Tailscale Serve is private to the tailnet and follows its access controls. Do
not use Tailscale Funnel for Hermes VNC or the Dashboard.

## Security

All host ports remain bound to `127.0.0.1`. Do not change them to a public
interface just to enable remote access; use Tailscale Serve and restrict
tailnet access instead.

Do not commit API keys, tokens, credentials, runtime data, or Docker volume
exports. The real Crawl4AI `.env` is ignored; only the empty `.env.example`
belongs in Git. Public configuration files describe how to generate
credentials rather than storing their values.
