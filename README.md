# Local AI Containers

Docker-based local AI stack using LM Studio as the inference backend.

## Services

- Open WebUI
- Hermes Agent
- SearXNG

All persistent runtime data is stored in Docker named volumes.

## Architecture

```text
LM Studio (macOS)
       │
       │ host.docker.internal:1234
       │
Docker ├── Open WebUI
       ├── Hermes
       └── SearXNG
            │
            └── Internet

Shared Docker network:
local-ai-network
```

## Requirements

- macOS
- Docker Desktop
- LM Studio
- Tailscale (optional)

## Initial Setup

Create the shared Docker network once:

```bash
docker network create local-ai-network
```

Start SearXNG:

```bash
cd searxng
docker compose up -d
```

Start Open WebUI:

```bash
cd ../open-webui
docker compose up -d
```

Initial Hermes setup:

```bash
cd ../hermes
docker compose run --rm hermes setup
docker compose up -d
```

## LM Studio

Run the LM Studio API server on port `1234`.

Docker containers connect using:

```text
http://host.docker.internal:1234/v1
```

## LM Studio Token Usage Monitoring

You can monitor the actual token usage of local LLM inference running through LM Studio in real time.

The following command reads LM Studio model output logs and displays both per-request and cumulative token usage.

```bash
lms log stream --source model --filter output --json --stats |
awk '
{
    line=$0

    if (match(line, /"promptTokensCount":[0-9]+/)) {
        s=substr(line,RSTART,RLENGTH)
        sub(/.*:/,"",s)
        input=s+0
    } else next

    if (match(line, /"predictedTokensCount":[0-9]+/)) {
        s=substr(line,RSTART,RLENGTH)
        sub(/.*:/,"",s)
        output=s+0
    } else output=0

    if (match(line, /"totalTokensCount":[0-9]+/)) {
        s=substr(line,RSTART,RLENGTH)
        sub(/.*:/,"",s)
        total=s+0
    } else total=input+output

    requests++
    total_input+=input
    total_output+=output
    total_all+=total

    printf "\nRequest #%d\n", requests
    printf "  Input : %'\''d\n", input
    printf "  Output: %'\''d\n", output
    printf "  Total : %'\''d\n", total

    printf "\nCumulative\n"
    printf "  Input : %'\''d\n", total_input
    printf "  Output: %'\''d\n", total_output
    printf "  TOTAL : %'\''d\n", total_all
    fflush()
}'
```

Example output:

```text
Request #1
  Input : 96,117
  Output: 996
  Total : 97,113

Cumulative
  Input : 96,117
  Output: 996
  TOTAL : 97,113
```

- **Input**: Total number of tokens processed as input for the request.
- **Output**: Total number of tokens generated by the model. For reasoning models, this includes reasoning/thinking tokens.
- **Total**: Input + Output.
- **Cumulative**: Total usage accumulated since the monitor was started.

Because the monitoring is performed directly from LM Studio's model logs, it captures inference regardless of which client generated the request, such as Hermes Agent, OpenCode, or Open WebUI.

> Cumulative values are kept only for the lifetime of the command and reset when the monitor is restarted.


```bash
docker compose build --pull

```

Check connected containers:

```bash
docker network inspect local-ai-network
```

```text
open-webui
hermes
searxng
```

## Remote Access with Tailscale

Services remain bound to `127.0.0.1`.

Open WebUI:

```bash
/Applications/Tailscale.app/Contents/MacOS/Tailscale serve --bg --https=443 localhost:3000
```

SearXNG Dashboard:

```bash
/Applications/Tailscale.app/Contents/MacOS/Tailscale serve --bg --https=8443 localhost:8888
```

Check:

```bash
/Applications/Tailscale.app/Contents/MacOS/Tailscale serve status
```

## Security

Do not commit API keys, tokens, credentials, runtime data, or Docker volume exports.
